# Movie Nation — Software Quality Assurance Project

A Software Quality Assurance (QA) portfolio project demonstrating manual testing documentation, test case design, bug reporting, and an introduction to automation and performance testing.

## Project Overview

This project focuses on planning and documenting QA activities for a movie ticket booking application called **Movie Nation**.

## Testing Activities

- **Test Planning:** Defined the testing scope and approach.
- **Manual Testing:** Prepared test cases for application features and user workflows.
- **Bug Reporting:** Created a structured bug report template.
- **Automation Testing:** Included Cypress learning and testing notes.
- **Performance Testing:** Included Apache JMeter notes.

## Repository Structure

- `QA-Documentation/Test-Plan.md` — Test plan
- `QA-Documentation/Manual-Test-Cases.md` — Manual test cases
- `QA-Documentation/Bug-Report-Template.md` — Bug report template
- `QA-Documentation/Cypress-JMeter-Notes.md` — Automation and performance testing notes

## Tools and Technologies

- Manual Testing
- Cypress

## Project Purpose

Created for educational and portfolio purposes to demonstrate QA documentation and testing knowledge.
